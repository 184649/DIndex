# Windows 受入確認

通常データに触れないようREADMEの独立 `DINDEX_DATA_DIR` と一時検索rootを使います。

- 起動はトレイのみ。ダブルクリックで表示、閉じるで常駐、終了でプロセス終了。同じprofile二重起動を拒否。
- ×／Alt+F4で閉じても「タスクトレイで動作中」の通知が出ない。トレイから開き直して繰り返し閉じても通知は出ず、索引・検索は継続できる。トレイの「終了」ではプロセスが残らない。
- 空検索、名前、パス、複数語、日本語、大小文字、結果上限。更新前と同じ一致集合/ランキング。
- 入力を続ける/戻す/検索方式変更/再索引連打中に、古い入力の結果・完了表示が戻らない。継続的なファイル更新中でもsnapshot結果を表示し、更新中表示の後に再検索される。
- 大量結果のスクロール、画面拡大率100/150/200%、操作継続中の検索表示。
- フォルダー配下作成/変更/削除、子孫を含むrename、対象外からsubtree移入、除外folderの孫、root追加削除。
- junction/symlink循環を含むテストrootで無限走査しない。リンク追跡の仕様を確認。
- 索引中に取消/終了し、再起動でcacheが空/部分状態にならない。
- cache破損、primary不在backupあり、両方破損、書込不可、保存取消。原本と正常backup保全。
- rootオフライン/アクセス拒否/監視overflow時の状態表示と再整合。失敗を正常0件と誤認しない。
- 開く/親folder/clipboardの失敗はアプリを落とさず説明。
- 更新器はテストディレクトリのダミー本体だけで検証。実配布サーバーへ公開しない。

## 性能

同じWindows機、電源設定、対象ファイル/ソート/検索意味で旧DIndex・本branch・Everything stable/betaを分けて測定します。warm/cold、初回索引、cache起動、更新反映、入力から最初の表示と全結果を分離。各30回以上の中央値/p95、割当、peak/private working set、CPU、結果件数/同順IDを保存してください。

クラウド合成C#ベンチの改善倍率をこのGUI/Everything比に置き換えません。
